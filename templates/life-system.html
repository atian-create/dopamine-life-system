01

我是什么样的人

从真实经历里找重复出现的行为。这里的示例请换成你自己的记录。

我的做事循环

1

观察生活

把这一小步做完，再开始下一步。

2

动手试一试

把这一小步做完，再开始下一步。

3

留下记录

把这一小步做完，再开始下一步。

4

分享给朋友

把这一小步做完，再开始下一步。

好奇心

对新东西，先做一个小实验

把一个周末留给散步、观察和动手。

→ 先试一个能在一天内完成的版本。

分享欲

做完以后，想讲给朋友听

记录过程和遇到的问题，比只展示结果更有意思。

→ 写下一个别人能照着做的步骤。

节奏

给创作留一块完整的时间

一段专注的时间，加一段出去走走的时间。

→ 把休息也排进计划。

价值观

想做的事，要能持续

衡量一个项目时，也看它做完后给自己的感受。

→ 记录自己的选择理由。

我的能量表

＋ 充电

  • 散步和旅行
  • 做一个小作品
  • 和朋友聊发现
  • 完整的休息

－ 耗电

  • 一天切换太多任务
  • 没有边界的答疑
  • 为了更新而更新
  • 一直坐着不休息
02

我的优势线索

不是心理测评；用具体行为、证据和适用场景描述自己。

表达

能把一个小发现讲清楚

示例证据：朋友看过步骤后能复现。

→ 适用：教程、分享会、个人介绍。

观察

会注意生活里的小细节

示例证据：散步时记下三种不同的店招。

→ 适用：城市记录、选题、设计。

归纳

把零散记录变成一页说明

示例证据：把旅行笔记整理成地图。

→ 适用：清单、模板、复盘。

03

我怎么表达

记录自己的语言习惯，不用套成统一的人设。

开头

先讲眼前发生的小事

今天散步的时候，我发现了一家……

→ 把场景说具体。

过程

让别人看见你怎么做

我先试了这个版本，然后改了一处。

→ 放出前后对比或过程截图。

结尾

留下一个可照着做的入口

你也可以从自己的一个小记录开始。

→ 给一个步骤、一份模板或一个作品。

04

我的边界

让机会经过自己的尺度，而不是让每个机会都变成任务。

时间

保留每天的一段空白

临时任务来了，先看有没有打断休息。

→ 约定清楚截止日期。

范围

一个阶段只守住一个重点

新想法先放进待尝试清单。

→ 下次复盘再决定。

合作

先说清楚交付与责任

哪些我负责，哪些需要别人参与。

→ 用一页说明对齐。

05

我现在在做什么

把生活、作品和项目放在同一张地图里。

生活

每周一次城市散步

记录街道、食物和见到的人。

→ 每周一页散步笔记。

作品

做一本周末小册子

把照片和记录编成一份分享页。

→ 先做 4 页的小版本。

项目

把经验整理成一个模板

用自己真的用过的内容做例子。

→ 先请一位朋友试用。

06

我会卡在哪

把卡点写成可调整的动作，先解决一个。

开始

总想等一个更完整的版本

先完成一个能打开的页面。

→ 今天只做首页。

切换

想法太多，注意力被拆散

把新想法暂存，每周固定挑一次。

→ 保留一个进行中的作品。

复盘

做完就忘了记录

作品完成当天，留一张截图和三句话。

→ 记录：做了什么、学到什么、下次改什么。

07

系统怎么运行

计划要能执行，也要允许调整。

每天

完成一件小事

选一个最想做的动作，留出专注时间。

→ 晚上记下一句今天的发现。

每周

留下一页记录

看看什么让自己充电、什么需要减量。

→ 选下周的一个重点。

每月

回看方向

哪些想继续，哪些可以暂时放下。

→ 更新这一页人生系统。

08

还能做什么

按自己的兴趣和余量选一个，不必同时开始。

绿灯

做一份散步地图

复用已有照片和路线，先发给朋友。

→ 一个周末能完成。

黄灯

试一次小型分享

先讲一个真实做过的小项目。

→ 确认准备时间后再决定。

红灯

同时开三个新项目

容易把时间切得太碎。

→ 留在待尝试清单。
