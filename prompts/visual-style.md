# 视觉风格提示词 / Visual-style prompt

## 中文

请采用「多巴胺配色 + 新粗野主义粗描边和硬阴影 + 卡通贴纸式编辑排版」。背景是奶油色纸面，叠一层很淡的点阵；正文是深紫黑色。主色包含亮粉、橙、蓝、紫、草绿、黄色与薄荷绿，按章节分配，不把所有颜色挤在一张卡片里。卡片 3px 深色描边、20–26px 圆角，阴影为 4–6px 的实色偏移。标题大而有性格，正文用清晰的系统中文字体。用徽章、编号、标签、少量旋转贴纸和人物插画做节奏，内容的层级比装饰更重要。手机单列，长表格可横滑；提供锚点目录和减少动态效果的适配。参考页只复用设计，不复用其中的私人事实。

## English

Use dopamine colors, Neo-brutalist outlines and hard shadows, and illustrated sticker-style editorial layouts. Start with cream paper and a subtle dot grid, with dark purple-black text. Assign saturated pink, orange, blue, purple, green, yellow and mint across sections rather than cramming them into each card. Use 3px dark borders, 20–26px rounded corners and solid shadows offset by 4–6px. Make headings expressive and body text easy to read. Build rhythm with badges, numbering, labels, occasional rotated stickers and character illustrations. Prioritize content hierarchy over decoration. Stack cards on mobile, let wide tables scroll, provide anchor navigation and respect reduced motion. Reuse the reference design, not its private facts.
