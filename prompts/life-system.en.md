# Life-system page prompt

Use my supplied page or screenshot as a visual reference. Create a personal life-system page that helps me understand my behavior, energy, voice, boundaries and next steps, and that I can share with friends.

My material:
- Name and brief introduction: [fill in]
- Three to five actual experiences: [fill in]
- My own notes and recurring phrases: [fill in]
- What recharges or drains me: [fill in]
- Work I no longer want to do and collaboration boundaries: [fill in]
- Current projects, obstacles and routines: [fill in]

Organize eight sections: who I am, clues to strengths, expression, boundaries, current work, obstacles, rhythm and next steps. Ground each interpretation in a real example. Mark missing evidence as pending; do not invent experiences, metrics or psychological conclusions.

Match the visual reference: cream dot-grid background, saturated pink/orange/blue/purple/green/yellow, bold dark outlines, hard shadows, rounded cards, sticker labels, large headings and occasional illustrations. Include anchor navigation and a readable mobile layout. Use only gentle motion and respect reduced-motion preferences.

Use my images: [paths or attachments; otherwise use simple shapes]. Do not treat the example person's image, name or experiences as mine.

Deliver a complete page that opens directly, actual browser screenshots and a short editing guide. If a Chinese version is requested, keep both versions equivalent in meaning.
